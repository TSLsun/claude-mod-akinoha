# 秋葉 Akinoha

日式簡約的秋日主題：和紙色的底、墨色枝條與金黃銀杏葉。畫面角落的落葉堆會隨著 context 用量越積越厚，提示列也會顯示目前百分比，在 60%、75%、90% 時跳出提醒，建議你 /compact 或開新對話。訊息使用不透明的底色與襯線字體，背景不干擾閱讀。

A warm, minimal Japanese autumn look for Claude. Golden ginkgo leaves drift down the edges of the window and pile up in the bottom corners as the context window fills. A quiet band above the prompt shows the percentage, and toasts appear at 60, 75 and 90 percent suggesting /compact or a fresh session.

## 安裝 Install

在 Claude Code 對話中輸入 / At the prompt of a Claude Code session:

```
/plugin install akinoha --marketplace TSLsun/claude-mod-akinoha
```

在終端機 / From a shell:

```bash
claude plugin install akinoha --marketplace TSLsun/claude-mod-akinoha
```

桌面版 App / In the desktop app: 點輸入框旁的 **＋** → **Plugins** → **Add marketplace**，輸入 `TSLsun/claude-mod-akinoha`，再按 **Add plugin**。

背景、配色與字型只在 Claude 桌面版與手機 App 顯示；終端機會顯示提示列、狀態列與通知。
